# Web mẫu Vercel

Project mẫu dùng React + Vite, sẵn sàng deploy lên Vercel.

## Chạy trên máy

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy Vercel

1. Upload toàn bộ thư mục này lên GitHub.
2. Vào Vercel.
3. Import repository.
4. Framework Preset: Vite.
5. Build Command: `npm run build`
6. Output Directory: `dist`
7. Bấm Deploy.
